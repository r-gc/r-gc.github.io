# 关于

这里是我给自己留的一块长期空间。

它会放技术文章，也会放一些没那么正式的东西：项目复盘、学习笔记、配置记录、代码片段，还有偶尔冒出来的 Web 小实验。

我更希望这里像一间工作室，而不是一面只展示结果的墙。项目做完之后，真正有价值的往往不是“它存在过”，而是中间的判断、踩坑、取舍和以后还能复用的经验。

所以这里会慢慢整理几类内容：

- [项目](/projects/)：记录正在做和做过的东西，不追求一次写完
- [笔记](/notes/)：保存那些以后大概率还会翻出来看的短记录
- [实验室](/lab/)：放一些动画、音乐、视频和交互页面实验

主要工程项目会按 `rgc318` 账号和本地工作区来整理；`r-gc/r-gc.github.io` 只是这个博客本身的托管仓库。
