# 关于

这里会整理我的技术文章、项目记录、学习笔记和一些 Web 小实验。

我希望这个站点不是单纯的文章列表，而是一个可以长期生长的个人空间：

- 写清楚做过什么、学到什么、踩过什么坑
- 保存代码片段、项目复盘和配置笔记
- 展示一些带动画、音乐、视频或交互效果的页面
- 把零散想法慢慢整理成可搜索、可回看的知识库

当前会先按这些栏目组织内容：

- [项目](/projects/)：项目展示、技术栈、截图和复盘
- [笔记](/notes/)：学习记录、配置备忘和短内容
- [实验室](/lab/)：动画、音乐、视频和交互页面实验
